02 / L’essentiel

On se retrouve
au bord de l’eau.

Deux saisons, deux tarifs+

Basse saison : 2 octobre–30 avril. Haute saison : 1er mai–1er octobre. Les deux prix sont indiqués dans cet ordre.

Ce qui est inclus+

Combinaison, matériel de sécurité et coaching bateau sont inclus dans les tarifs. Pour la navigation surveillée, l’autonomie doit être validée après un cours.

Le rendez-vous+

Départ des Issambres, secteur port de San Peïre / base de voile. Stéphane confirme le point précis et choisit le spot selon les conditions.

Parlons de votre sortie+

Cours privés, semi-privés, groupes sur demande et bons cadeaux personnalisés. Envoyez un SMS si Stéphane est sur l’eau : il vous rappelle.
